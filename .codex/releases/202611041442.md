# Instant durable chats release

Source commit: `2ef25cca57e5d1a636cbf1cf02278f774dc412fd` on `main`, pushed to origin.

## Changes

- Create a chat immediately with a bundled name, Claude Default and the default host. Use another reachable host at creation and retain offline creation and queued messages.
- Share the session controls and composer. Show intermediate text, tool calls, tool results and subagent activity. Dismiss the keyboard by tapping outside the input. Hide chat-owned sessions from the main session list.
- Let the chat update its own name, instructions, memory and model after an explicit user request. Apply changes on later turns, with revision checks. Scheduled work cannot change the profile.
- Retry hidden-directory notification registration when an older host returns success without acknowledging its filters.
