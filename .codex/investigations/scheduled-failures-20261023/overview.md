## Remove policy contradictions, then add readiness checks

Thirteen prompts contain the revised policy. Nine still retain an explicit all-items completion rule below it.
Some also retain a mandatory 30-like threshold. The prefix overrides those rules, but the duplication creates ambiguity.

Rewrite each saved prompt around one authoritative policy reference. Keep identity, ownership, permissions and deadlines firm.
Keep sample sizes, query counts and likes as work targets. Record helper findings separately from the canonical verdict.

Then check provider capacity, phone reservation and visibly loaded app content before starting engagement.
Use the existing retry model to preserve the logical occurrence. Disabled schedules need separate authorization before activation.

The post-session hook synchronizes a final structured verdict. It does not re-grade older evidence when policy changes.
Task completion and feed quality also remain separate. Broad fitness relevance does not prove alignment with the intended audience.
