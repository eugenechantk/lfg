## Log

### 2026-10-17 — FlowDeck UI capture session replaced by another session

**What happened:** `flowdeck ui simulator session start` wrote to `.flowdeck/automation/sessions/<id>/` in the shared repo; a minute later the directory was gone because another agent started its own session (starting a session stops the previous one, per project dir).
**Why it matters:** Reads of `latest.jpg` failed and could have shown another agent's screen.
**What better looks like:** In this repo, use one-off `flowdeck ui simulator screen -S <udid> --output <own path>` captures (script `shot.sh` in the scratchpad), never the shared session recorder. Worth a line in the flowdeck skill or ios/CLAUDE.md.

### 2026-10-17 — Boards drawn before measuring the app

**What happened:** I drew the iPad proposal boards with the detail column at x=340 (sidebar card edge + 10). The app's detail column starts at x=330; the list button sits 20pt into it beside the list and 10pt from the screen edge without it. I had to regenerate and republish the boards.
**Why it matters:** The verifier compares against the boards; a board that disagrees with unchanged app geometry produces false FAILs and wasted rounds (see memory measure-before-the-verifier).
**What better looks like:** Before drawing a board for an existing screen, measure the unchanged parts from a raw capture first (column origins, button positions, insets), then draw only the change on top.

### 2026-10-17 — Launch fix verified in one orientation only

**What happened:** Starting the split view at `.doubleColumn` drew the sidebar 55pt low; deferring the change past the first render fixed portrait, and I moved on. The landscape launch still showed the offset. Disabling my change proved it was pre-existing: any first frame that shows the sidebar lays both columns out 55pt low (tab container at y=32) until a hide/show toggle.
**Why it matters:** I nearly shipped a launch fix that left landscape broken, and would have blamed it on later steps.
**What better looks like:** For any launch-state or size-class change on iPad, measure every orientation it applies to (cold launch in each), and run the "old path" control once before attributing a layout bug to my change.

### 2026-10-17 — Screen auto-lock breaks Simulator GUI automation

**What happened:** After ~30 min, `osascript` failed with "Can't get window ... of process Simulator" because the Mac had re-locked.
**What better looks like:** Check `lfg-unlock status` before each Simulator.app GUI step; re-run `lfg-unlock unlock` when it reports locked. Lock again when the GUI work ends.

### 2026-10-17 — No FlowDeck path for rotation or landscape taps

**What happened:** FlowDeck has no device-rotation command. Rotation worked via Simulator.app's Device > Rotate Left on the session's own window (AXRaise + front-window name check, so another session's sim is never rotated). In landscape, FlowDeck `touch` still takes portrait coordinates and `screen` returns a portrait-oriented 1.45x image: px = 834 - ly, py = lx.
**What better looks like:** Save the rotate + `tchl.sh` conversion recipe somewhere durable (memory or ios/CLAUDE.md) so the next iPad audit does not rediscover it.

### 2026-10-17 — A sidebar column reports a compact size class on iPad

**What happened:** I gated the iPad header inset on `horizontalSizeClass == .regular` inside `SessionListView`. Inside a `NavigationSplitView` sidebar column the environment is COMPACT, so the fix silently did nothing; three rebuilds went to padding/offset/focus experiments before I checked the flag.
**What better looks like:** Decide "am I in the iPad sidebar?" in the view that owns the split view (RootView knows: `usesSidebarDock`) and pass it in. When a layout change has no visible effect, first prove the branch runs (a 1-frame colour change or a log) before changing the layout code.

### 2026-10-17 — Full-board verifier rounds grade chrome the pass never touched

**What happened:** Round 1 returned FAIL with 18 findings; ~14 were pre-existing styling or my boards drawing unchanged chrome approximately (glass fills, dock, placeholder, New-session composer).
**What better looks like:** When a design pass changes layout only, say so on the canvas (a "how to read" sticky) and scope the verifier to the changed components from the start; or draw unchanged chrome by importing the live S2/A2 boards instead of redrawing it.
