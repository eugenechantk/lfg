## Log

### 2026-09-15 — gpt-6-astra vanished from the iOS picker after the 1.3.0 build

**What happened:** Eugene reported the Codex model picker lost `gpt-6-astra`. The option was added to `ios/LFGCore/Sources/LFGCore/Models.swift` and `desktop/LFGSessions.swift` around 2026-09-06 but never committed; every LFG TestFlight build from 09-06 to 09-13 was archived from the dirty main tree and carried it. Today's 1.3.0 (202609151621) was archived from `.worktrees/ios-terminal` — a clean checkout at HEAD — so the committed list (sol/terra/luna/spark) shipped and astra regressed.
**Why this was wrong:** Mirror image of the "main can be broken while every build is green" hazard: a feature that only exists as uncommitted edits ships for a week, then silently disappears the first time someone builds from a clean tree. Nine days of builds gave false confidence that the change was "in".
**What better looks like:** Before archiving from a worktree, diff the worktree against the main tree's dirty files for the app target (`git -C <main> diff --stat -- ios desktop`) and call out anything user-visible that will be absent. Small, self-contained config changes like a model list should be committed the same day they're made, not left riding in the dirty tree.
