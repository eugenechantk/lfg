### 2026-08-25 — Patch-staging recipe for committing into a dirty shared tree

Not a mistake — a workflow worth persisting. To land ONE clean commit while shared files
carry other sessions' uncommitted hunks: (1) `cp` each dirty shared file aside BEFORE
editing, (2) edit in place, (3) `diff -u snapshot current` → per-file patch with `a/`/`b/`
headers, (4) `git apply --cached <patch>` (index is at HEAD, so only your hunks stage),
(5) `git checkout-index --prefix` into a temp dir and run typecheck+tests on the staged
tree itself (it is a different combination than the working tree), (6) verify the unstaged
remainder's diffstat matches the pre-task foreign diff exactly, (7) commit. Also smoke-test
`git revert --no-commit` in a throwaway worktree when revertability is a requirement.
Candidate for a skill or a note in the repo CLAUDE.md if it recurs.
