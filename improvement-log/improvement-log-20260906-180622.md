**What happened:** Followed memory `air-ssh-access` (`ssh eugenechan@eugenes-macbook-air`): hostname didn't resolve, `.local` didn't resolve, the pinned LAN IP from `mosh-bridged` said "Host is down". ### 2026-09-07 — Pipeline exit status hid an ssh failure inside a fallback loop

**What happened:** `ssh A … | head -30 && break` — `head` returns 0 regardless of ssh's exit, so the loop `break`-ed after the failed first target and never tried the second.
**What better looks like:** Put the fallback decision on the command itself (`if ssh … > out; then …`) or `set -o pipefail`; don't chain `&& break` after a pipe.

### 2026-09-07 — Scripted `jq` against `/api/sessions` before eyeballing its shape

**What happened:** The first live probe after the server restart used `jq '.[] | select(.agent=="codex")'` and failed with "Cannot index array with string" because the endpoint returns `{sessions: […]}`. One wasted round-trip.
**Why this was wrong:** Memory `probe-shape-before-scripting` says exactly this: run the probe once and look at the record before parsing it.
**What better looks like:** `curl … | head -c 300` first, then write the filter. For lfg specifically: the list endpoint is an object with a `sessions` array; the messages endpoint is a bare array.

### 2026-09-07 — Grep-filtered FlowDeck output hid a successful command

**What happened:** `flowdeck ui simulator session start … --json | grep -o …` printed nothing because FlowDeck pretty-prints JSON with spaces around colons (`"success" : true`), so the compact-JSON pattern matched nothing. Re-ran unfiltered.
**Why this was wrong:** Same class as above — assumed an output shape.
**What better looks like:** For FlowDeck `--json`, pipe through `python3 -c 'import json,sys; …'` or `jq`, never a regex tuned to compact JSON.
