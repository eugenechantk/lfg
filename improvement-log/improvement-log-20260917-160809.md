### 2026-09-18 — launchctl bootstrap I/O error after bootout

**What happened:** Repointed the LaunchAgent, ran `bootout; sleep 2; bootstrap`. Bootstrap returned `5: Input/output error`; the lfg-pro tunnel (phone + ssh-pro) was down until a retry 40 s later. The dead-man revert would have called the same `bootstrap` and could have failed the same way.
**Why this was wrong:** launchd sometimes rejects a bootstrap for a label it is still tearing down. One attempt with no retry is not a safe restart sequence for a service other things depend on.
**What better looks like:** Restart sequence = `bootout`, then `until launchctl bootstrap …; do sleep 2; done` capped at 5 tries, then verify the process and sockets. A dead-man must use the same retried sequence. Consider `launchctl kickstart -k` when only the wrapper script (not the plist) changed — no bootstrap needed.
