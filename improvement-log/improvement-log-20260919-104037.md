## Log

### 2026-09-19 — Verified the tap path, not the gesture the flow promised

**What happened:** The feature doc's user flow said "Tap it, or keep swiping to full-swipe", but every live check (mine and the auditor's) revealed the button with a short swipe and then tapped it. Eugene's first reply: "I should not need to tap the button to mark as unread only swipe to a certain point will mark as unread". The behaviour was already correct (SwiftUI's `allowsFullSwipe` defaults to true) — the write-up and evidence made it look like a tap was required.
**Why this was wrong:** A criterion that names two gestures needs evidence for both. I picked the one that was easier to screenshot (the revealed button is visible; a committed full swipe just shows the row gone) and the auditor prompt inherited the same bias.
**What better looks like:** For swipe actions, drive the full swipe as the PRIMARY proof (`--from 10,y --to 395,y`) and treat the revealed-button screenshot as supplementary. Write the summary around the gesture the user will actually make, not the one that photographs well.

### 2026-09-19 — `scroll --until` no-op

**What happened:** Needed a row that had just moved from Unread into Idle, below the fold. `flowdeck ui simulator scroll --until "Asian character scene storyboard"` returned success but the screenshot was unchanged (twice). Collapsing the Unread group by tapping `sessionGroupHeader-status-4` brought Idle on screen instantly.
**Why this was slow:** Session-row labels are not the title text in the tree, so `--until` never matched and the command still reports success. Two round trips plus a `--help` read.
**What better looks like:** In lfg's list, use group-header collapse (`sessionGroupHeader-status-N`) to reach a section, not scrolling. Generally: read the tree once for the label shape before using `--until`.

### 2026-09-19 — prefix `--by-id` tap

**What happened:** Tapped `--by-id "markRead-"` hoping for prefix match on `markRead-<sessionId>`; FlowDeck matched exactly and suggested labels instead.
**What better looks like:** When the identifier carries an unknown suffix, tap by the visible label (`tap "Mark Read"`) or pull the full id from `latest-tree.json` first.

### 2026-09-19 — zsh `====` again

**What happened:** `echo ====` inside a compound Bash command died with `=== not found` (zsh `=word` path expansion), which also swallowed the `ls` before it. Memory `zsh-bare-equals-word-aborts-command` already covers this.
**What better looks like:** Quote separators (`echo '===='`) or use `---`.
