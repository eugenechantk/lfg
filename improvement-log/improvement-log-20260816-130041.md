### 2026-08-16 — Concurrent agent's in-flight edit broke my `flowdeck run`

**What happened:** `flowdeck build` passed, then minutes later `flowdeck run` failed with a `sending`-parameter concurrency error in `LFGCore/Sources/LFGCore/LFGClient.swift:543` — a file I never touched. `stat` showed an mtime seconds old: another lfg session was mid-edit. Waited until the file's mtime aged past 60s, rebuilt clean.
**Why this was a cost:** ~3 minutes and one false "did I break it?" beat. The repo CLAUDE.md warns about concurrent edits to shared files, but only for *editing*; the same hazard applies to *building* — a green build is a snapshot of someone else's tree too.
**What better looks like:** When a build fails in a file the session never edited, `stat -f %m` it before reading any code. Age < ~2 min ⇒ concurrent edit, wait it out; don't diagnose or "fix" it.
