### 2026-10-09 — Cloudflare-hosting rule doesn't fit Design-canvas artifacts

**What happened:** Published the LFG UI map as a Design canvas (11 `.dc.html` artboards + `canvas.json`). The global rule says every published Artifact also gets hosted on Cloudflare as a standalone page. A canvas depends on the type's runtime (`support.js`, `dc-runtime.js`) and has no single HTML file to wrap, so the rule cannot be followed as written. Skipped it and said so.
**Why it matters:** The rule was written for single-file HTML artifacts. Without an exception, every canvas session either breaks the rule silently or wastes time trying to flatten a canvas.
**What better looks like:** Add an exception to `~/.claude/CLAUDE.md`: Design-canvas (typed) artifacts are exempt; offer a static export (screenshots or a flattened HTML gallery) only when the direction is settled and Eugene wants to share it.

### 2026-10-09 — Fresh audit screenshots made the UI recreation fast

**What happened:** Drawing the current phone and desktop UI took one pass because `.codex/evidence/task-list-chrome/*-audit/` and `release-20261009/` held screenshots from the same day. Without them I would have needed a simulator run plus a desktop window-shot.
