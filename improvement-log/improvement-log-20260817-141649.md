### 2026-08-17 — Guessed the client instead of looking at the screen

**What happened:** "some air sessions disabled" — I assumed the iOS client and spent ~8 calls reading `SessionStore.isOffline`, `MultiHost`, dimming logic. The disabled rows were in the macOS desktop app (`canOpen == tmuxName != nil`). One `screencapture -x` showed the greyed Air rows, the missing `tmux` chip, and both host dots green — the whole answer.
**Why this was wrong:** Eugene works from a Mac with the desktop app open; a screen capture is one call and is ground truth. Memory [[ground-truth-before-hypothesizing]] already says this.
**What better looks like:** When a symptom names a UI ("disabled", "not showing") and the display is reachable, `screencapture -x` FIRST, then read the source for the surface it actually is.

### 2026-08-17 — Killed the evidence: relaunched the desktop app without dumping its state

**What happened:** The running desktop instance (up 3d8h) showed only 12 of 49 live sessions — every one in `fiftyworkout`, none in `lfg`/`inbox`/`.gbrain`. A fresh run of the SAME binary with the SAME config (`--hidden-dirs-probe`) reported 45 visible across 7 directories, so it was in-memory drift. I proved the data path was fine, then quit and relaunched — which fixed it and destroyed the only copy of the bad state.
**Why this was wrong:** The app has no way to report its own live state, and SwiftUI exposes nothing through System Events AX, so the in-memory `hiddenDirs`/`searchQuery` died with the process. The cause is now unfalsifiable: `setHiddenDirs` swallows save errors with `try?` (memory and disk can diverge silently), but `hidden-dirs.json` was last written Aug 12 with one entry, which argues against it. Cannot distinguish.
**What better looks like:** Before restarting a long-running GUI process that is misbehaving, capture whatever state IS reachable — and if nothing is, that gap is the bug to fix first. Concretely, `desktop/` needs a state dump (a debug menu item or a signal handler that writes `hiddenDirs`, `searchQuery`, per-host session counts to a file), and `setHiddenDirs`'s `try?` should surface the failure. Then a recurrence is one command, not a lost session.
