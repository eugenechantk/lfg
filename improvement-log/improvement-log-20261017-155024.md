### 2026-10-18 — Repeated the Python f-string backslash SyntaxError in a canvas generator

**What happened:** The merge generator (`gen/merge.py`) failed twice on `f-string expression part cannot include a backslash` — the same error `desk.py` hit earlier in this session. Each cost a fix-and-rerun round.
**Why this was wrong:** The macOS system `python3` is older than 3.12, so escaped quotes inside `{...}` are illegal. I knew this from the first failure and wrote the same pattern again.
**What better looks like:** In HTML generators, build any markup that needs inner quotes as a plain variable before the f-string, or use string concatenation. Run `python3 -c "import ast; ast.parse(open(f).read())"` before the first real run.
