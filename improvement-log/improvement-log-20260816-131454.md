### 2026-08-16 — Missed a second copy of the composer

**What happened:** I generalized `ComposerAttachment` and rewired `MessageComposer`, then hit a build failure from `NewSession/NewSessionComposer.swift`, a near-duplicate composer I never saw. My survey grep was `ios/LFG/*.swift`, which does not recurse.
**Why this was wrong:** A shell glob is not a search. `grep -rn` over `ios/` would have found it in the first pass, before I'd designed the change around a single call site. The duplication itself was the deeper problem — it is exactly why the new-session screen would have silently kept the photos-only picker.
**What better looks like:** When changing a shared type, `git grep` the TYPE NAME across the whole repo before designing, not `*.swift` in one directory. And when the same logic turns up twice, extract it (which is what fixed this — `AttachmentTray.swift` now owns it once).

### 2026-08-16 — Wrote test expectations from my head instead of running the function

**What happened:** Three test expectations were wrong on first run (`.gitignore` → I guessed `file.gitignore`, actual `gitignore.dat`; `a";rm -rf /;.txt` → I forgot the embedded `/` splits the path; `emoji😀.png` → I forgot trailing underscores are stripped). Each cost a test-run cycle.

**What better looks like:** For a pure function with fiddly string edges, run it over the edge-case list first, eyeball the outputs, THEN freeze them into expectations. Reserve hand-written expectations for cases where I'm asserting a requirement rather than describing behaviour.
