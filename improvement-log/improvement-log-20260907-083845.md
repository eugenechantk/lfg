## Log

### 2026-09-07 — Three Bash probes lost to zsh `=word` expansion

**What happened:** Used `echo ====` / `echo =====RETRY` as section separators in compound commands; zsh treats a bare `=cmd` token as "path of cmd" and aborted the whole command ("===== not found"), so three multi-part probes returned nothing and had to be re-run with quotes.
**Why this was wrong:** Known zsh behaviour; each failure cost a round-trip on the critical path of a live bug report.
**What better looks like:** Quote separators (`echo '====='`) or use `printf -- '-----\n'`; never start an unquoted word with `=` in this shell.

**What happened:** Spent the first stretch reading sendq trace + pane heuristics before dumping the transcript's non-user/assistant entry types. The `queue-operation` lines (enqueue / remove absorbed_mid_turn) answered the question outright.
