## Log

### 2026-07-31 — Stale hostname in `air-ssh-access` memory

**What happened:** Asked how to SSH into the Pro. The `[[air-ssh-access]]` memory said `ssh eugenechan@eugenes-macbook-pro-2`; that failed with `Could not resolve hostname`. `tailscale status` showed the real MagicDNS name is `eugenes-macbook-pro`. Also, the `tailscale` CLI isn't on PATH — had to invoke `/Applications/Tailscale.app/Contents/MacOS/Tailscale`.

**Why this mattered:** A remembered hostname is live state, not a durable fact — Tailscale node names change when a device is removed/re-added. Handing Eugene the memorized command without testing it would have shipped a broken answer.

**What better looks like:** For any remembered host/pid/UDID/path, run the one-shot probe before quoting it (matches [[probe-shape-before-scripting]]). Fixed: memory updated with the correct name, the full Tailscale binary path, and a note that MagicDNS names should be re-checked rather than trusted.
